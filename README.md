# To-Do Console

Консольное приложение «Список дел» на Java.

## Возможности

- добавление, удаление задач
- отметка задачи выполненной
- поиск по части названия
- показ только выполненных и только невыполненных задач
- сохранение в текстовый файл и загрузка при запуске
- защита от неправильного ввода

## Как запустить

1. Установи JDK 17 или новее.
2. Склонируй репозиторий:
git clone https://github.com/dulatelubay/todo-console.git
3. Открой проект в IntelliJ IDEA.
4. Запусти класс `Main`.

## Структура проекта

- `Task`: одна задача (id, название, статус)
- `TaskManager`: хранение списка, поиск, фильтры, сохранение и загрузка
- `Main`: консольное меню

## Используемые темы

ООП, коллекции (`ArrayList`), исключения, Stream API и лямбды, работа с файлами (`Files`).

## Формат файла `tasks.txt`

Одна задача на строку: `id;название;выполнена`

    1;Купить хлеб;true
